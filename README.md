# Machine Learning Using Different Algorithms

A collection of machine learning projects implementing and comparing various algorithms 
across regression, classification, clustering, and ensemble methods. Each folder contains 
a hands-on implementation with real datasets, covering the full workflow from data 
preprocessing to model evaluation.

## Contents

| # | Algorithm | Type | Description |
|---|-----------|------|-------------|
| 1 | [Simple and Multiple Linear Regression](./1.%20Simple-and-Multiple-Linear-Regression) | Regression | Predicting continuous outcomes using one or more input variables |
| 2 | [Random Forest Classification](./2.%20Random-Forest-Classification) | Classification | Ensemble of decision trees for classification tasks |
| 3 | [Logistic Regression](./3.%20Logistic-Regression) | Classification | Binary/multiclass classification using logistic function |
| 4 | [Ridge & Lasso Regression](./4.%20Ridge-Lasso-Regression) | Regression | Regularized regression to reduce overfitting |
| 5 | [Decision Tree](./5.%20Decision-Tree) | Classification/Regression | Tree-based model for decision rules |
| 6 | [Naive Bayes](./6.%20Naive-Bayes) | Classification | Probabilistic classifier based on Bayes' theorem |
| 7 | [Support Vector Classification](./7.%20Support-Vector-Classification) | Classification | Margin-based classification using SVM |
| 8 | [K-Means Clustering](./8.%20K-Means-Clustering) | Clustering | Unsupervised partitioning into K clusters |
| 9 | [Hierarchical Clustering](./9.%20Hierarchical-Clustering) | Clustering | Tree-based unsupervised clustering |
| 10 | [PCA](./10.%20PCA) | Dimensionality Reduction | Reducing feature space while preserving variance |
| 11 | [DBSCAN Clustering](./11.%20DBSCAN-Clustering) | Clustering | Density-based clustering for irregular shapes |
| 12 | [XGBoost](./12.%20XGBoost) | Ensemble | Gradient boosting for high-performance prediction |

## Tech Stack
- Python
- pandas, numpy
- scikit-learn
- matplotlib / seaborn
- Jupyter Notebook

## How to Use
1. Clone the repository
2. Navigate to the folder for the algorithm you're interested in
3. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
4. Open the `.ipynb` file in Jupyter Notebook and run the cells

## About
This repo was built as part of my journey learning and applying machine learning 
algorithms to real-world datasets, with a focus on understanding when and why to use
